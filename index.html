Falta configurar Firebase

Cinco minutos, una sola vez. Después no lo tocás más.

  1. Entrá a console.firebase.google.com y creá un proyecto (podés desactivar Analytics).
  2. En el menú lateral: Realtime Database → Crear base de datos → elegí la región → arrancá en modo de prueba.
  3. Volvé a Configuración del proyecto (el engranaje) → bajá hasta Tus apps → tocá el ícono </> (Web) → registrá la app.
  4. Firebase te muestra un bloque firebaseConfig. Copiá esos valores dentro de config.js, en la carpeta de esta página.
  5. Asegurate de que databaseURL esté completo — es el que termina en .firebasedatabase.app. Si no aparece en el bloque, copialo de la pantalla de Realtime Database.
  6. Recargá esta página.
Sobre el «modo de prueba»: deja la base abierta para cualquiera que tenga el link. Para una lista de baby shower entre familia está bien, pero tiene fecha de vencimiento (30 días) y cualquiera con la URL podría escribir. Si querés que dure más, en la pestaña Reglas de Realtime Database poné {"rules":{".read":true,".write":true}}. Es igual de abierto, pero sin vencimiento.
